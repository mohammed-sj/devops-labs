# DevOps Labs

Hands-on DevOps labs, built while working through the CoderCo DevOps bootcamp. Each lab has the real files, proof it worked, and what broke along the way.

## Structure

```
devops-labs/
├── 01-linux/        # Linux fundamentals        in progress
├── 02-bash/         # Bash scripting            planned
├── 03-git/          # Version control           planned
├── 04-networking/   # How the internet works    planned
├── 05-docker/       # Containers                planned
├── 06-aws/          # Cloud (AWS)               planned
├── 07-terraform/    # Infrastructure as code    planned
├── 08-cicd/         # CI/CD pipelines           planned
└── 09-kubernetes/   # Container orchestration   planned
```

Each module contains:
- **labs/** – one folder per lab: the write-up, the real files, and what broke
- **notes/** – my own explanations, backed by real output
- **projects/** – larger builds

A module's folder appears with its first lab. **Done** means its final checkpoint is passed and written up.
